## [0.1.0] — 2026-04-25

### Added
- Initial release of Find My Files for Windows
- Search files and folders by name (partial match) or extension (`*.ext`)
- Configure one or more drives to scan; save defaults in Settings
- Add extra drives at search time without changing saved defaults
- Results presented in a sortable, filterable table: Name · Path · Size · Modified · Type
- Export results as `.csv` or styled `.html` report
- Search history — last 50 queries stored locally; click any to re-run
- Open any result file or folder directly in Windows Explorer
- Dark mode (cyberpunk neon) and Light mode (clean SaaS); persists across sessions
- Cancel in-progress search at any time
- Status bar shows result count and elapsed time
